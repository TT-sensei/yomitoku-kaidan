# よみとく階段

小学3・4年生の国語「読むこと」の学習アプリです。よむたんけん（1・2年生）のステップアップ版として作りました。

- 文章はすべてオリジナル：3年生・4年生 各14本（物語7＋説明7）、全28本・196問
- 問題の種類：根拠さがし（答えの文を本文からタップ）、指示語（何をさすかを打ち込み）、打ち込み（接続語など）、構成（段落のはたらき）、要旨、様子、図表（表を読む）
- 1・2年生版との違い：タップだけでなく、ローマ字入力での打ち込み回答を入れ、問題のレベルを上げています
- 間違えた問題は端末内に記録され、「とっくん」で再挑戦して正解すると記録が消えます（特訓に敵・HP・タイマーはありません）
- 本文は縦書き。読む画面と解く画面は一体で、文章は右側（約7割）に固定表示され、左側（約3割）に「まずは読んでみましょう」の案内→問題が出る。文章が動かないので視線が固定され、解くときもスクロール不要
- 問題文・選択肢・指示語の文も縦書き（よむたんけん式）。解説は問題カードの中に出て、選択肢側が縮んで1画面に収まる。打ち込みの入力欄だけは横書き
- ふりがなON/OFF、音ON/OFF（端末に保存）
- データ保存はlocalStorageのみ。外部API・外部サービスは使いません（共通基盤の edu-effects / sounds-recipe- / ナビキャラ画像は TT-sensei の公開資産を参照）

## 構成
- index.html（アプリ本体）
- texts/index.json（文章ファイルの一覧）
- texts/<id>.json（文章1本ごとのデータ。文章と問題の追加・編集はここ）
- 問題のつくり方.md（他のAIや人が文章・問題を追加するための形式ガイド）
- assets/hero.webp（図書室で本を読むナビキャラの場面絵）

## 打ち込みの判定
- 完全一致（accept）で判定するのが基本。全角・半角、カタカナ・ひらがな、空白や句読点の違いは吸収する
- 完全一致しなくても、問題ごとに決めたキーワード（keys）のグループが全て入力に含まれていれば正解にする
- 数字だけを答える問題は、誤判定を防ぐため完全一致のみ
